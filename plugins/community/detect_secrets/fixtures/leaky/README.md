# Фикстура конформных тестов detect_secrets

Каталог для проверки happy path: в нём есть ровно две находки — по одному
детектору каждого класса, чтобы тест проверял и тип, и номер строки.

Путь к каталогу передаётся плагину относительным (`fixtures/leaky`), потому что
подпроцесс плагина стартует в каталоге плагина — абсолютный путь в
plugin.test.yaml был бы привязан к машине.
